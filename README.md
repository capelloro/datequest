# DateQuest 💌

Интерактивный генератор бережных приглашений на свидание в формате короткой визуальной истории.

## Сценарий

3D-конверт → выбор ощущения → личное письмо → равноправный RSVP → готовый ответ для мессенджера.

## Возможности MVP

- 3 визуальных настроения приглашения;
- персональные имя, текст, место и дата;
- анимированные переходы, живой фон, реакции и конфетти;
- три честных ответа без давления;
- Web Share API и копирование готового ответа;
- адаптивный полноэкранный режим получателя;
- поддержка reduced motion и клавиатурной навигации;
- персональная ссылка вида `#invite=...`;
- режим получателя автоматически скрывает редактор;
- никаких сторонних JS/CSS-зависимостей и backend.

## Развёртывание GitHub Pages

1. Создайте **public** repository.
2. Загрузите содержимое проекта в корень репозитория.
3. Главная ветка должна называться `main`.
4. Откройте `Settings → Pages`.
5. В `Build and deployment → Source` выберите **GitHub Actions**.
6. Сделайте push в `main` или запустите workflow вручную из вкладки Actions.
7. GitHub покажет публичный URL после deployment.

Workflow уже лежит в `.github/workflows/pages.yml`.

## Локально

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Ограничение static MVP

GitHub Pages не умеет сохранять RSVP. Сейчас персонализация находится в URL fragment и не отправляется на сервер. Следующий production-шаг — вынести только `invite-id` и ответы в небольшой serverless backend/DB, оставив frontend статическим.
